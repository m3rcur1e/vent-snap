# Vent Snap

Turbine condensers and vent condensers snap onto steam vents. Hold one near a vent and the preview jumps onto it. This also works for a schematic that contains one, and the block stays on the vent when you rotate the schematic.

![Vent Snap](https://raw.githubusercontent.com/m3rcur1e/vent-snap/media/vent-snap.gif)

**Settings › Vent Snap** (or **Cur1e Mods**) has an on/off switch and the snap radius (2–10 tiles).
